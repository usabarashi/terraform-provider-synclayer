# synclayer_sxep200w_wifi_global

Manages the WiFi settings that apply to the whole device: Wi-Fi Protected Setup
(WPS) and mesh mode.

Each of these is a single value on the device rather than one per band or per
SSID, so they share one resource. Neither setting can be removed, so destroying
this resource **disables WPS** and **turns mesh mode off**.

## Example Usage

```terraform
resource "synclayer_sxep200w_wifi_global" "main" {
  wps_active = false

  # Mesh is off; this device is not part of a mesh network.
  mesh_mode = 0
}
```

## Argument Reference

- `wps_active` (Boolean, Optional) Whether Wi-Fi Protected Setup (WPS) is
  enabled.
- `mesh_mode` (Number, Optional) Mesh mode: `0` off, `2` mesh agent, `3` mesh
  controller.
- `mesh_backhaul_band` (String, Optional) Band used for the mesh backhaul (the
  device's `bhBand`). The values a device accepts depend on its hardware; the
  device reports the bands it supports, which the provider does not write.

Fields that are not set are left at their current device value.

## Management notes

- Only the attributes you set are written, so WPS and mesh can each be managed
  on their own.
- Destroying the resource **disables WPS** and sets `mesh_mode` to `0`.
- The WPS PIN is generated by the device. It is exposed as `wps_pin` and is
  never part of a write, so it cannot be set here and is left untouched by one.

## Attributes Reference

In addition to the arguments above:

- `wps_pin` (String, Sensitive) WPS PIN held by the device.

## Import

Import using the fixed id `global`:

```sh
terraform import synclayer_sxep200w_wifi_global.main global
```
